Aperçu

Coller dans Gmail

  1. Clique sur Copier la signature.
  2. Gmail → ⚙️ → Voir tous les paramètres → Signature.
  3. Crée ou sélectionne ta signature, clique dans la zone, puis Ctrl + V.
  4. Choisis-la pour les nouveaux e-mails, puis clique sur Enregistrer les modifications en bas de la page.
